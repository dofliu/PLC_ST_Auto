# UI4 測試報告:模擬儀表板(2026-11-11)

## 變更
- `plc_st/web.py`
  - 互動模擬 API:`POST /api/sim/start`(code/profile/scan_ms → session id、欄位、變數 meta、初始列)、`/api/sim/step`(`cycles` 1..5000、`set` 於第一個掃描前套用;輸出變數不可強制)、`/api/sim/stop`。Session 保存於伺服器記憶體,上限 16 個(LRU 淘汰)。
  - `/api/run` 回傳新增 `meta`:每欄位的型別與區段(input/output/inout/local),陣列元素與 STRUCT 欄位亦正確對應。
- `plc_st/interpreter.py`:指派/呼叫陳述式的執行期錯誤補上 `line N:` 前綴(最內層優先,不重複),UI 可直接標記錯誤行。
- `plc_st/web/index.html`(模擬頁籤重做)
  - **控制列**:執行(連續掃描)/暫停/單步/重設、速度 ×0.2/×1/×10、週期與時間時鐘、狀態徽章(暫停/執行中/批次回放/錯誤);`Alt+R` 執行/暫停、`Alt+S` 單步。連續執行採「等回應再排下一輪」避免請求堆積,每輪週期數依速度與掃描時間計算。
  - **I/O 面板**:輸入(BOOL 開關、數值/STRING 輸入框)、輸出(BOOL 燈號、數值)、內部變數;暫停時切換的輸入以琥珀框標示「待套用」,下一掃描生效(符合 PLC 讀取輸入映像的時序)。程式/profile/掃描週期變更後自動重新載入。
  - **波形**:每變數一條固定高度軌道(BOOL 26px、數值 46px,不再按畫布高度平分而重疊);STRING/非數值改為匯流排文字帶(值改變處交叉,解決 NaN);長名稱以 `…` 截斷;輸入/輸出名稱以藍/綠標示;數值軌顯示可視範圍 min…max;時間軸刻度;高 DPI 清晰;滾輪縮放(以游標為中心)、Shift+滾輪/拖曳平移、雙擊或按鈕全覽、放大/縮小按鈕;游標虛線 + 每軌數值框 + 「游標 週期 N · t ms」。互動執行時自動跟隨最新週期(最多保留 5000 列)。
  - **批次執行**(事件腳本)收進可展開區塊;執行後進入「批次回放」,滑鼠在波形上移動時 I/O 面板顯示該週期的值。
