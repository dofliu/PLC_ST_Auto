# UI8 測試報告:寬螢幕雙頁籤(2026-11-24)

UI7 報告列出的選配「寬螢幕同時顯示兩個頁籤」。只改前端 `plc_st/web/index.html`,後端 API 不變。

## 變更
- **雙頁籤按鈕**(頂列「雙頁籤」,僅視窗寬度 ≥1600px 顯示):開啟後右側頁籤區分成左右兩欄,各自獨立捲動。例如左欄「模擬」看波形、右欄「測試」跑情境,不必來回切換。
- **雙頁籤列**:顯示「左欄 X」、右欄下拉選單、「對調」、✕ 關閉。右欄選成與左欄相同時自動對調。
- **導覽列**:左欄頁籤為原本的實心標示,右欄頁籤以虛線框標示(`aria-current="location"`)。點一般頁籤換左欄;**Shift+點頁籤**或 **Alt+Shift+1~6** 指定右欄;點(或 Alt+數字)已在右欄的頁籤只會閃一下提示,不會兩欄重複。
- **程式內部切頁**(例如執行模擬會呼叫 `tab('sim')`、狀態列按鈕):目標頁籤已顯示於右欄時不再換掉左欄。
- **進入右欄時的初始化**:右欄為「匯出」時自動檢查各格式、編輯程式碼後重新檢查;右欄為「測試」時更新變數晶片。
- **分欄比例**:雙頁籤時另外記憶(`plcst.split2`,預設程式碼欄 34%),單頁籤仍用 `plcst.split`(預設 50%);雙擊/Enter 還原為各自預設值。
- **記憶**:`plcst.dual`、`plcst.tab2`;重新整理後還原。視窗縮小到 <1600px 時自動回到單頁籤(設定保留),再放大即恢復。
